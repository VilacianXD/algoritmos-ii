Ponteiros para structs

Uma struct também mora num endereço. Com um ponteiro para ela, uma função lê e altera os campos do registro original, e a seta -> deixa isso curto.

Exercícios

Um ponteiro que aponta para um registro

Uma variável do tipo struct ocupa memória como qualquer outra, então tem endereço, e um ponteiro pode guardá-lo. Os dois precisam ser do mesmo tipo estruturado.

typedef struct {
    char nome[100];
    char sexo;
    int telefone;
    char email[50];
} Agenda;

Agenda contato1, *contato2;   /* contato1 é a struct; contato2 é um ponteiro para Agenda */
contato2 = &contato1;         /* contato2 aponta para contato1 */

Daqui em diante, tudo que for feito através de contato2 acontece em contato1.

Acessar campos: (*p).campo e p->campo

Há duas formas, equivalentes:

(*contato2).sexo = 'M';   /* desreferencia e usa o ponto */
contato2->sexo = 'M';      /* a seta faz as duas coisas de uma vez */
  • Os parênteses em (*contato2).sexo são obrigatórios: o ponto tem precedência maior que o *, então *contato2.sexo tentaria acessar o campo de um ponteiro.
  • Regra prática: variável struct usa ponto (contato1.sexo), ponteiro para struct usa seta (contato2->sexo).
  • Para campos string, continue usando strcpy ou scanf: strcpy(contato2->nome, "Ana");, scanf("%d", &contato2->telefone);.
typedef struct { int x, y; } Ponto;

Ponto a = {3, 7};
Ponto *pa = &a;
printf("(%d, %d)\n", pa->x, pa->y);
(3, 7)
Praticar1 exercício, 3 versões cada

Funções que recebem Struct *

Passar a struct por valor copia todos os campos, e alterações não voltam. Passar o endereço evita a cópia e permite alterar o original: é a passagem por referência da A8, agora com registros.

typedef struct { int codigo; double preco; int quantidade; } Produto;

void preencherProduto(Produto *p) {
    scanf("%d %lf %d", &p->codigo, &p->preco, &p->quantidade);
}

void imprimirProduto(Produto *p) {
    printf("%d  R$ %.2f  %d un.\n", p->codigo, p->preco, p->quantidade);
}

int main() {
    Produto prod;
    preencherProduto(&prod);    /* envia o endereço */
    imprimirProduto(&prod);
    return 0;
}

Dentro da função, p é um ponteiro: campos com ->. Na main, prod é a própria struct: na chamada vai &prod.

Função que só calculaMesmo quando a função não altera nada, receber const Retangulo *r ou Retangulo *r evita copiar a struct. Ex.: double calcularArea(Retangulo *r) { return r->largura * r->altura; }, chamada com calcularArea(&ret).

Uma struct alocada com malloc

Juntando com a A9: dá para pedir memória para uma struct durante a execução. O ponteiro devolvido é usado com seta, e no fim vem o free.

typedef struct { char nome[50]; int idade; } Pessoa;

Pessoa *p = (Pessoa *) malloc(sizeof(Pessoa));
if (p == NULL) {
    printf("Erro de alocacao\n");
    return 1;
}
strcpy(p->nome, "Marina");
p->idade = 19;
printf("%s, %d anos\n", p->nome, p->idade);
free(p);
Marina, 19 anos
  • sizeof(Pessoa) já é o tamanho da struct inteira; não precisa somar os campos.
  • Não existe variável Pessoa comum aqui: o registro só é acessível pelo ponteiro.
  • Os exercícios 7, 9 e 10 da lista seguem o mesmo roteiro: alocar, testar NULL, preencher, passar o ponteiro para uma função de cálculo, mostrar e liberar.
