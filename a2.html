Funções e vetores

Um vetor passado para uma função não é copiado: vai o endereço do começo. Por isso a função consegue ler e alterar os elementos originais.

Vetor como parâmetro

Para declarar que um parâmetro é um vetor, usam-se colchetes vazios. Como a função não sabe o tamanho, ele costuma vir num segundo parâmetro.

int maximo(int vetor[], int tam) {
    int m = vetor[0];
    for (int i = 1; i < tam; i++)
        if (vetor[i] > m)
            m = vetor[i];
    return m;
}

Na chamada vai só o nome do vetor, sem colchetes:

int notas[10];
/* ... leitura ... */
int maior = maximo(notas, 10);
Chamadas erradas comunsmaximo(notas[], 10) não compila. maximo(notas[10], 10) envia um único elemento (e ainda fora do vetor, que vai de 0 a 9).

Por que a função altera o vetor original

Com uma variável simples, o parâmetro é uma variável nova que recebe uma cópia do valor (A1). Com vetor isso não acontece: nenhum vetor novo é criado.

Em C tudo é passado por valor, mas o “valor” de um vetor numa chamada é o endereço do primeiro elemento. A função recebe esse endereço e trabalha direto na memória do vetor de quem chamou.

Comparação da aulaPassar por valor é entregar uma fotocópia: rabiscar a cópia não muda o original. Passar o endereço é dizer onde o documento está: quem tem o endereço vai até lá e muda o original.
void zerarNegativos(int v[], int n) {
    for (int i = 0; i < n; i++)
        if (v[i] < 0)
            v[i] = 0;
}

int main() {
    int dados[4] = {3, -2, 5, -7};
    zerarNegativos(dados, 4);
    for (int i = 0; i < 4; i++) printf("%d ", dados[i]);
    return 0;
}
3 0 5 0

Essa ideia (enviar o endereço para a função mexer no original) é o que a A8 generaliza com ponteiros.

Strings em funções

String é vetor de char terminado em '\0', então vale tudo acima. Uma função pode preencher a string de quem chamou:

void solicitar_nome(char nome[], int tamanho_maximo) {
    printf("Por favor, digite seu nome: ");
    fgets(nome, tamanho_maximo, stdin);
}

void dar_boas_vindas(char nome[]) {
    printf("Ola, %s! Seja bem-vindo!\n", nome);
}

int main() {
    char nome_pessoa[50];          /* começa com lixo */
    solicitar_nome(nome_pessoa, 50);   /* fgets grava direto em nome_pessoa */
    dar_boas_vindas(nome_pessoa);
    return 0;
}

Para percorrer uma string, o laço vai até o terminador: for (i = 0; s[i] != '\0'; i++). Contar espaços, consoantes ou vogais é só trocar o teste dentro do laço.

Vetores não podem ser retornados

Tentar devolver um vetor declarado na função dá erro:

char[] solicitar_nome() {     /* não compila */
    char nome[50];
    fgets(nome, 50, stdin);
    return nome;
}

A solução é a da seção anterior: quem chama cria o vetor e passa para a função preencher. Quando a função precisa “devolver” vários números (a posição e o valor do maior, a quantidade e os elementos), ela devolve um deles pelo return e altera um vetor recebido, ou imprime direto.

Padrões que aparecem na lista

  • Maior e posição: guarde o índice (pos) e compare v[i] > v[pos]; no fim, o valor é v[pos].
  • Acima da média: dois laços. O primeiro soma; só depois de ter a média o segundo conta quem passa dela.
  • Vetores iguais: percorra os dois juntos; na primeira diferença, devolva 0; se o laço terminar, devolva 1.
  • Intersecção: laço dentro de laço: para cada a[i], procure um b[j] igual.
  • Remover repetidos: monte um novo tamanho k; copie v[i] para v[k] só se ele ainda não apareceu entre v[0] e v[k-1].
  • Pares antes dos ímpares mantendo a ordem: use um vetor auxiliar: primeiro copie os pares na ordem, depois os ímpares; então copie de volta.
  • Maior sequência crescente: conte o tamanho da sequência atual; quando v[i] <= v[i-1], recomece; guarde o melhor início e tamanho.
