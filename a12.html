Listas ligadas

Cada elemento vive num nó alocado na hora, e cada nó guarda o endereço do próximo. A lista cresce e encolhe sem mover ninguém de lugar.

Por que uma lista

Pense numa lista de espera: gente entra e sai o tempo todo, alguém desiste no meio, outra pessoa precisa entrar numa posição específica, e o tamanho é imprevisível. Um vetor, mesmo alocado com malloc, tem tamanho fixo e exige um bloco contíguo; inserir no meio obriga a deslocar todo mundo.

Uma lista ligada é uma coleção linear em que os elementos não ficam em posições consecutivas. Cada um sabe onde está o seguinte, então inserir e remover em qualquer ponto não desloca os outros.

  • Simplesmente encadeada: cada nó tem um dado e um ponteiro para o próximo. É a desta aula.
  • Duplamente encadeada: cada nó aponta para o próximo e para o anterior.
  • Circular: o último nó aponta de volta para o primeiro.

Exemplo dos slides: 13 aponta para 65, que aponta para 82, que aponta para 34. O último nó aponta obrigatoriamente para NULL: ele não tem sucessor.

O nó

typedef struct No {
    int info;           /* o dado guardado */
    struct No *prox;    /* endereço do próximo nó */
} No;
  • struct No dá um rótulo à struct para que ela possa se referir a si mesma ainda dentro da definição.
  • info guarda o dado (aqui um inteiro, mas pode ser qualquer coisa, até uma struct).
  • prox é um ponteiro para outro No: uma estrutura autorreferenciada. Se vale NULL, o nó é o último.

Com No *p;: p é o endereço de um nó, p->info é o conteúdo, p->prox é o endereço do próximo.

Seta, não pontoNós são acessados por ponteiro, então é sempre p->prox. p.prox não compila, porque p não é uma struct.

Criar um nó e uma lista vazia

No *criar_no(int val) {
    No *no = (No *) malloc(sizeof(No));
    if (no == NULL)
        exit(1);
    no->info = val;
    no->prox = NULL;
    return no;
}

No *criar_lista_vazia() {
    return NULL;
}

int lista_vazia(No *lista) {
    if (lista == NULL)
        return 1;
    else
        return 0;
}

A lista inteira é representada por um ponteiro para o primeiro nó (a cabeça). Lista vazia é esse ponteiro valendo NULL. Na main: No *lista = criar_lista_vazia();.

Lista vazia: a cabeça aponta para NULL.

Inserir no início e no final

No início

No *inserir_inicio(No *lista, int val) {
    No *no = criar_no(val);
    no->prox = lista;      /* o novo aponta para o antigo primeiro (ou NULL) */
    return no;            /* o novo passa a ser a cabeça */
}

Funciona para lista vazia e não vazia. Como a cabeça muda, quem chama precisa guardar o retorno: lista = inserir_inicio(lista, 27);.

Inserir 27 no início de uma lista que tinha só o 13.

No final

No *inserir_final(No *lista, int val) {
    No *no = criar_no(val);
    if (lista_vazia(lista))
        return no;                  /* lista vazia: o novo é o primeiro */
    No *aux = lista;
    while (aux->prox != NULL)       /* para no último nó */
        aux = aux->prox;
    aux->prox = no;                 /* o último passa a apontar para o novo */
    return lista;                   /* a cabeça não mudou */
}

O ponteiro auxiliar aux percorre a lista sem mexer na cabeça. A condição é aux->prox != NULL, e não aux != NULL: o laço precisa parar no último nó, não depois dele.

Percorrer: imprimir, contar, somar

Quase toda operação usa o mesmo esqueleto: um auxiliar começa na cabeça e anda de prox em prox até virar NULL.

void imprimir(No *lista) {
    if (lista == NULL) {
        printf("Lista vazia\n");
        return;
    }
    No *aux = lista;
    while (aux != NULL) {
        printf("%d ", aux->info);
        aux = aux->prox;
    }
    printf("\n");
}
  • Contar: troque o printf por cont++.
  • Média: some aux->info, conte, e divida no final (cuidado com lista vazia e com divisão inteira).
  • Ocorrências: some 1 quando aux->info == x.
  • Comparar duas listas: ande com um auxiliar em cada uma; se algum info diferir, são diferentes; no fim, as duas precisam ter acabado juntas.
Esquecer de avançarSem aux = aux->prox; o laço nunca termina. E usar a própria cabeça (lista = lista->prox) para percorrer dentro de uma função não estraga a lista de quem chamou, mas fora dela perderia o começo.

Buscar um elemento

No *buscar_elemento(No *lista, int val) {
    No *aux = lista;
    while (aux != NULL) {
        if (aux->info == val)
            return aux;       /* achou: endereço do nó */
        aux = aux->prox;
    }
    return NULL;              /* percorreu tudo e não achou */
}

É o retorno de ponteiro da A11 aplicado a nós. A lista 7 pede também searchinsert(l, x): busca x e, se não achar, insere e devolve o nó novo. E pede trocar dois elementos m e n: buscando os dois nós, basta trocar os campos info com um auxiliar, sem mexer nos ponteiros.

buscar_elemento(lista, 8) devolve o endereço do terceiro nó.

Liberar a lista

No *liberar_lista(No *lista) {
    No *aux = lista;
    while (lista != NULL) {
        aux = lista;
        lista = lista->prox;   /* guarda o caminho ANTES de liberar */
        free(aux);
    }
    return NULL;
}

Cada nó veio de um malloc, então cada um precisa do seu free. A ordem importa: se o nó atual for liberado antes de ler prox, o resto da lista fica inalcançável. Use assim: lista = liberar_lista(lista);.
