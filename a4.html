Achar um valor entre 100.000

Um sistema guarda 100.000 matrículas e precisa saber se a 57342 está lá e em que posição. É preciso olhar todas? Por onde começar? E se as matrículas estivessem ordenadas?

A aula responde com dois algoritmos: a busca sequencial (funciona em qualquer vetor) e a busca binária (exige vetor ordenado, mas é muito mais rápida).

Praticar1 exercício, 3 versões cada

Busca sequencial

Compara cada elemento, do primeiro ao último, com o valor procurado.

int busca_sequencial(int vet[], int n, int x) {
    for (int i = 0; i < n; i++)
        if (vet[i] == x)
            return i;      /* achou: devolve a posição e encerra */
    return -1;             /* percorreu tudo: -1 não é posição válida */
}
  • Melhor caso: o valor está na primeira posição, 1 comparação.
  • Pior caso: está na última ou não existe, n comparações.
  • Variações da lista: contar comparações (um contador antes do if), mostrar todas as posições (não dar return ao achar), contar ocorrências, achar o mais próximo (guardar a menor diferença abs(vet[i] - x)).

No exemplo acima a sequencial compara 15, 8, 32, 4 e 27: cinco comparações.

Busca binária

Com o vetor ordenado, compara o valor com o elemento do meio. Igual: achou. Menor: descarta a metade da direita. Maior: descarta a da esquerda. Repete enquanto houver intervalo.

int busca_binaria(int vet[], int n, int x) {
    int inicio = 0, fim = n - 1, meio;
    while (inicio <= fim) {
        meio = (inicio + fim) / 2;
        if (vet[meio] == x)
            return meio;
        if (vet[meio] < x)
            inicio = meio + 1;    /* x está à direita */
        else
            fim = meio - 1;       /* x está à esquerda */
    }
    return -1;                     /* o intervalo ficou vazio */
}

Busca por 68 em [6 13 21 29 35 42 51 68 74 90]. Se o valor não existe, o laço termina quando inicio passa de fim.

  • Para vetor em ordem decrescente, inverta as decisões: se vet[meio] < x, o valor está à esquerda.
  • Para achar a primeira ocorrência de um valor repetido, ao encontrar guarde meio e continue procurando à esquerda (fim = meio - 1).
  • Quando não encontra, inicio termina exatamente na posição onde o valor deveria ser inserido.

Quanto cada uma custa

A cada comparação a binária descarta cerca de metade do que sobrou. Por isso o pior caso é por volta de log₂(n) comparações.

O preço da binária é o vetor ordenado. Ordenar custa caro uma vez; se depois vierem milhares de consultas, o investimento se paga. É a resposta da questão 12 da lista: ordenar as matrículas uma vez e passar a usar busca binária.
