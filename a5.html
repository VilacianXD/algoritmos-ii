Structs

Um registro junta dados de tipos diferentes que formam uma coisa só: um aluno, um produto, uma turma. Cada campo se acessa com um ponto.

Definir um registro

Uma agenda de celular tem, para cada contato, nome, telefone, e-mail, sexo… Com vetores separados para cada dado, seria difícil manter tudo junto. A struct (registro) é um tipo composto que agrupa variáveis, possivelmente de tipos diferentes, que formam uma entidade.

struct agenda {
    char nome[100];
    char sexo;
    int telefone;
    char email[50];
};

O espaço ocupado é, de modo geral, a soma dos espaços dos campos. Para dados simples e homogêneos (só uma idade, só as notas de 5 alunos) uma variável ou um vetor basta; struct faz sentido quando vários dados juntos descrevem uma coisa.

Com typedef

typedef struct {
    char nome[100];
    char sexo;
    int telefone;
    char email[50];
} Agenda;

struct agenda contato1;   /* com struct nomeada: precisa da palavra struct */
Agenda contato2;          /* com typedef: o nome do tipo basta */

Acessar, atribuir e ler campos

Campo a campo, com o operador ponto: variavel.campo. Cada campo se comporta como uma variável comum do seu tipo.

struct agenda contato;
strcpy(contato.nome, "Luã Marcelo");   /* string: strcpy, nunca = */
contato.sexo = 'M';
contato.telefone = 99999999;
printf("%s %c %d\n", contato.nome, contato.sexo, contato.telefone);
typedef struct { char descricao[81]; int codigo; float preco; } Produto;

Produto a;
scanf(" %s", a.descricao);   /* string: sem & */
scanf("%d", &a.codigo);      /* número: com & no campo */
scanf("%f", &a.preco);
Erros comunscontato.nome = "Ana"; não compila: vetor de char não recebe atribuição, use strcpy. Produto.preco está errado: o ponto vai na variável, não no tipo.

Vetor de structs

Para 100 alunos, em vez de 100 variáveis, um vetor em que cada posição é um registro completo:

typedef struct { char nome[50]; int matricula; float media; } Aluno;

Aluno alunos[5];
for (int i = 0; i < 5; i++) {
    scanf(" %49[^\n]", alunos[i].nome);
    scanf("%d %f", &alunos[i].matricula, &alunos[i].media);
}
printf("%s\n", alunos[1].nome);    /* nome do aluno da posição 1 */

A sintaxe é vetor[indice].campo. Os algoritmos das aulas anteriores continuam valendo: procurar pela matrícula (busca sequencial comparando alunos[i].matricula), achar o maior preço (guardar o índice do maior), filtrar (estoque menor que 5), separar em dois vetores (aprovados e reprovados, cada um com seu contador).

Structs dentro de structs

Quando um campo é ele mesmo composto (um endereço, uma data), ele pode ser outra struct. Duas formas:

typedef struct {              /* forma 1: struct declarada dentro */
    int registro;
    char nome[100];
    struct { int dia, mes, ano; } Nascimento;
} Cadastro;

typedef struct { int dia, mes, ano; } Data;   /* forma 2: tipo separado */
typedef struct {
    int registro;
    char nome[100];
    Data nascimento;
} Cliente;

O acesso encadeia pontos: cliente.nascimento.dia = 17;, e num vetor clientes[1].nascimento.mes = 11;.

Struct como parâmetro de função

void imprimir_dados(Agenda contato) {
    printf("%s %c %d\n", contato.nome, contato.sexo, contato.telefone);
}

int main() {
    Agenda contato1;
    /* ... preencher ... */
    imprimir_dados(contato1);
}

Por valor, a função recebe uma cópia da struct inteira: ler os campos funciona, mas alterações não voltam para a main. Para alterar (ou evitar copiar um registro grande), passa-se o endereço: assunto da A10. Vetores de struct, como qualquer vetor, já vão por endereço: void listar(Aluno v[], int n) enxerga e altera os registros originais.

Várias structs ligadas por id (lista 2)

A segunda lista usa quatro tipos e um conjunto de dados fixo na main:

typedef struct { int id; char nome[50]; int idade; } Aluno;
typedef struct { int id; char nome[50]; } Professor;
typedef struct { int idAluno; float nota1, nota2, nota3; } Nota;
typedef struct {
    int id;
    int idProfessor;          /* não é struct: é o id do professor */
    char disciplina[50];
    int alunosTurma[50];      /* ids dos alunos */
    int qtdAlunos;
    Nota notas[50];
    int qtdNotas;
} Turma;

As structs não guardam umas às outras: guardam ids. Para mostrar o nome do professor de uma turma, procura-se no vetor professores aquele cujo id é igual a turmas[t].idProfessor. Para o nome de um aluno a partir de uma nota, procura-se em alunos o id igual a notas[k].idAluno. É uma busca sequencial (A4) dentro de vetores de struct.
