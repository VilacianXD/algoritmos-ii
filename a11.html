Retorno de ponteiro

Às vezes o resultado não é um valor, e sim um lugar. A função devolve o endereço de onde a resposta está, e quem chamou pode ler ou alterar ali mesmo.

Saber o valor ou saber onde ele está

Com float notas[5] = {7.5, 5.0, 8.5, 6.0, 9.0};, achar a menor nota é fácil:

float menorNota(float notas[], int n) {
    float menor = notas[0];
    for (int i = 1; i < n; i++)
        if (notas[i] < menor)
            menor = notas[i];
    return menor;
}

Mas a função devolve uma cópia: 5.0. Se depois for preciso corrigir exatamente essa nota no vetor, o 5.0 sozinho não diz em que posição ela está. Funções que devolvem int, float ou char entregam o valor, não a localização.

A saída é a função devolver o endereço da menor nota.

A sintaxe tipo *funcao(...)

tipo *nome_funcao(parametros) {
    tipo *ptr;
    /* comandos */
    return ptr;
}

O * antes do nome diz que o retorno é um ponteiro para tipo. Exemplo dos slides: entre dois inteiros, devolver o endereço do maior.

int *maior(int *p, int *q) {
    if (*p > *q)
        return p;
    else
        return q;
}

int main() {
    int a = 10, b = 20;
    int *resultado = maior(&a, &b);
    printf("Maior: %d\n", *resultado);
    *resultado = 0;                 /* zera b, a variável que tinha o maior */
    printf("%d %d\n", a, b);
}
Maior: 20
10 0
  • p e q já guardam endereços, então o return não usa &.
  • Quem chama guarda o retorno num ponteiro do mesmo tipo (int *resultado) e usa * para ler ou alterar.

Devolver o endereço de uma posição do vetor

float *menorNota(float notas[], int n) {
    int pos = 0;
    for (int i = 1; i < n; i++)
        if (notas[i] < notas[pos])
            pos = i;
    return &notas[pos];
}

pos guarda o índice da menor nota; notas[pos] é o valor (5.0); &notas[pos] é o endereço onde o 5.0 está. Como a função foi declarada float *, ela precisa devolver um endereço, e é ele que vai no return.

float *m = menorNota(notas, 5);
*m = 6.0;     /* a nota 5.0 foi corrigida direto no vetor */
Nunca devolva o endereço de uma variável localUma variável declarada dentro da função deixa de existir quando ela termina. Devolver &menor (local) entrega um endereço inválido. Devolva endereços de coisas que continuam vivas: parâmetros que já eram ponteiros, posições do vetor recebido ou memória alocada com malloc.

Quando não há o que devolver: NULL

Uma busca pode não encontrar nada. Nesse caso a função devolve NULL, e quem chama testa antes de usar.

int *buscar(int vet[], int n, int valor) {
    for (int i = 0; i < n; i++)
        if (vet[i] == valor)
            return &vet[i];   /* achou: endereço do elemento */
    return NULL;              /* não achou */
}

int *r = buscar(v, 6, 42);
if (r != NULL)
    printf("Achei: %d\n", *r);
else
    printf("Nao encontrado\n");

O mesmo vale para structs: Funcionario *buscarFuncionario(Funcionario *f1, Funcionario *f2, int matricula) devolve f1, f2 ou NULL.

Funções que alocam e devolvem

O caso mais comum de retorno de ponteiro: a função chama malloc, confere, e devolve o endereço do bloco novo. A memória alocada continua existindo depois que a função termina, então devolver esse endereço é seguro.

typedef struct { int codigo; char titulo[81]; double preco; } Livro;

Livro *alocarLivro() {
    Livro *l = (Livro *) malloc(sizeof(Livro));
    return l;              /* pode ser NULL se faltou memória */
}

int main() {
    Livro *livro = alocarLivro();
    if (livro == NULL) return 1;
    livro->codigo = 7;
    /* ... preencher, exibir ... */
    free(livro);
    return 0;
}

Ponteiros devolvidos também servem para escolher entre duas structs: Produto *menorPreco(Produto *a, Produto *b) devolve a ou b, e a main mostra os dados pelo ponteiro escolhido.
