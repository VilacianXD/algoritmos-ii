Funções

Por que separar código em funções

Calcular a área de um quadrado 5 vezes resolve-se com um for. Mas e se não se sabe quantas vezes nem quando o cálculo vai acontecer? Copiar as mesmas quatro linhas em vários pontos do programa é frágil:

printf("Digite o lado do quadrado: ");
scanf("%f", &lado);
area = lado * lado;
printf("A area do quadrado e: %.2f\n", area);

A solução é separar esses comandos do corpo do main e dar um nome a eles. Isso é uma função (também chamada de módulo).

  • Uma função agrupa comandos que só executam quando ela é chamada.
  • Pode devolver um resultado para quem a chamou.
  • printf, scanf e fgets são funções prontas da stdio.h.

Definir uma função

tipo nome_funcao(lista de parametros) {
    sequencia de comandos;
    return algo_do_tipo;
}

Lê-se: nome_funcao é uma função do tipo tipo que recebe uma lista de parâmetros, executa os comandos e retorna algo do tipo tipo.

ParteO que é
tipoTipo do valor devolvido: int, float, char… ou void se não devolve nada.
nome_funcaoIdentificador usado para chamar. Mesmas regras de nome de variável: sem espaço, sem começar com número, sem palavra reservada.
parâmetrosVariáveis de entrada, cada uma com seu tipo, separadas por vírgula: (int a, float b). Vazio ou (void) se não recebe nada.
returnDevolve o valor e encerra a função na hora.
int area_quadrado(int lado) {
    int area;
    area = lado * lado;
    return area;          /* poderia ser só: return lado * lado; */
}

Chamar uma função

Escreve-se o nome e, entre parênteses, os valores para os parâmetros. Se a função retorna algo, a chamada vira aquele valor: guarde numa variável do mesmo tipo ou use direto.

a = area_quadrado(aresta);                       /* o valor de aresta vai para lado */
printf("Area: %d\n", area_quadrado(aresta));     /* ou direto no printf */
  • Os argumentos são atribuídos na ordem: em multiplicacao(x1, x2), a = x1 e b = x2. Trocar a ordem troca quem recebe o quê.
  • Se a função exige um parâmetro e a chamada não envia, há erro.
  • A função precisa estar definida (ou declarada) antes do ponto em que é chamada.
Lembrete da lista de definição e chamadaSe a função tem return, a chamada precisa de algo para receber o valor: a = media(nota1, nota2, nota3);. Chamar só media(nota1, nota2, nota3); calcula e joga o resultado fora.

Funções void

void indica que a função não devolve valor: ela só executa uma tarefa (imprimir, mostrar menu, preencher dados). O return; sem valor é opcional e serve para sair antes do fim.

void cumprimentar() {
    printf("Seja bem-vindo!\n");
}

int main() {
    cumprimentar();      /* chamada sozinha: não há valor para guardar */
    return 0;
}
Erro clássicox = cumprimentar(); não compila: uma função void não tem valor para atribuir.

Parâmetros e retorno juntos

#include <stdio.h>

int multiplicacao(int a, int b) {
    int c = a * b;
    return c;
}

int main() {
    int x1 = 4, x2 = -10;
    printf("Multiplicacao: %d\n", multiplicacao(x1, x2));
    return 0;
}
Multiplicacao: -40

Os parâmetros funcionam como variáveis locais que nascem com os valores enviados. Isso é passagem por valor: a função recebe cópias. Mudar a dentro da função não muda x1 (a A8 mostra como mudar o original com ponteiros).

O return também pode devolver uma expressão inteira: return a * b;. E pode aparecer em vários pontos, como em if (n > 0) return 'P'; else return 'N';.

Escopo: local e global

O escopo de uma variável diz em que partes do código ela pode ser usada.

  • Local: declarada dentro de uma função (inclusive os parâmetros). Só existe ali e some quando a função termina. c de multiplicacao não é visível no main, e res do main não é visível em multiplicacao.
  • Global: declarada fora de todas as funções, acima do main. Qualquer função lê e altera, e ela existe o programa inteiro.
int global_valor = 10;

void mostra_valores() {
    int local_funcao = 20;
    printf("%d %d\n", global_valor, local_funcao);
}

int main() {
    int local_main = 5;
    global_valor = 15;          /* altera a global */
    mostra_valores();
    printf("%d %d\n", global_valor, local_main);
    return 0;
}
15 20
15 5

Se uma local tem o mesmo nome de uma global, a local oculta a global dentro daquela função. Globais dificultam a leitura e a manutenção e ocupam memória o tempo todo: devem ser evitadas.
