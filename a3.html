Ordenação

Três jeitos de colocar um vetor em ordem comparando elementos: trocar vizinhos, escolher o menor, ou inserir cada um no lugar certo.

O problema e as três estratégias

Dado 15 -20 100 2 5 10 -1, queremos -20 -1 2 5 10 15 100. Há muitos algoritmos (bubble, selection, insertion, merge, quick, heap…); eles diferem no tempo e na memória que usam, e todos os desta aula se baseiam em comparações e ordenam dentro do próprio vetor.

MétodoIdeia
Bubble sort (troca)Compara vizinhos e troca os que estão fora de ordem; a cada passada o maior “borbulha” para o fim.
Selection sort (seleção)Procura o menor da parte não ordenada e o troca com o primeiro dessa parte.
Insertion sort (inserção)Pega o próximo elemento e o insere na posição certa da parte já ordenada, deslocando os maiores.

Bubble sort

Percorre o vetor várias vezes. Em cada passada compara vet[j] com vet[j+1] e troca se o da esquerda for maior. Ao fim da primeira passada o maior elemento está na última posição; nas seguintes ela não precisa mais ser comparada.

void bubble(int vet[], int tamanho) {
    int i, j, aux;
    for (i = 0; i < tamanho - 1; i++)              /* passadas */
        for (j = 0; j < tamanho - 1 - i; j++)      /* parte não ordenada */
            if (vet[j] > vet[j + 1]) {
                aux = vet[j];
                vet[j] = vet[j + 1];
                vet[j + 1] = aux;
            }
}
  • Com n elementos são n − 1 passadas; a passada i compara n − 1 − i pares.
  • Para ordem decrescente, troque o teste para vet[j] < vet[j + 1].
  • Simples, in-place (O(1) de memória extra) e estável, mas O(n²) e com muitas trocas.

Selection sort

Na iteração i, assume que o menor está em i, procura de i + 1 até o fim um menor ainda e, se achar, troca com a posição i. Depois disso a posição i está definitiva.

void selection(int vet[], int tamanho) {
    int i, j, indice_minimo, aux;
    for (i = 0; i < tamanho - 1; i++) {
        indice_minimo = i;
        for (j = i + 1; j < tamanho; j++)
            if (vet[j] < vet[indice_minimo])
                indice_minimo = j;
        if (indice_minimo != i) {
            aux = vet[i];
            vet[i] = vet[indice_minimo];
            vet[indice_minimo] = aux;
        }
    }
}
  • Faz no máximo n − 1 trocas: bom quando escrever na memória é caro.
  • Faz sempre o mesmo número de comparações, n(n − 1)/2, esteja o vetor como estiver: O(n²) em todos os casos.
  • Não é estável. Para ordem do maior para o menor, procure o maior (vet[j] > vet[indice]).

Insertion sort

Divide o vetor em parte ordenada (início) e não ordenada. A cada passo pega a chave = vet[i] e, de trás para frente, desloca para a direita quem for maior que ela, abrindo um buraco onde ela entra.

void insertion(int vet[], int n) {
    int i, j, chave;
    for (i = 1; i < n; i++) {
        chave = vet[i];
        j = i - 1;
        while (j >= 0 && vet[j] > chave) {
            vet[j + 1] = vet[j];    /* desloca para a direita */
            j = j - 1;
        }
        vet[j + 1] = chave;         /* insere no buraco */
    }
}
  • Muito bom para vetores pequenos e quase ordenados: perto de O(n) nesse caso.
  • Estável. Pior caso (vetor invertido) O(n²), com muitos deslocamentos.
  • Natural quando os dados chegam aos poucos e o vetor precisa continuar ordenado: cada novo valor é só mais uma inserção.
